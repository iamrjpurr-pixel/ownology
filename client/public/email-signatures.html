Email signatures — copy & paste.

Three signature variants: Rich, Gel, and a generic support version. Each preview below is the actual HTML — the same rendered result you’ll get in Gmail, Apple Mail, Outlook, etc. Click “Show HTML”, copy all, paste into PrivateEmail (or Namecheap Webmail) → Settings → Signature editor → toggle “Rich text / Source” to HTML mode → paste.

Editing your details: before pasting, tweak the phone, LinkedIn URL, or role. Use plain text where the signature says [edit]. Image loads from https://ownology.ai/ownology-logo-mark-512.png once deployed. On the dev preview it’s served from ownership-dev.preview.emergentagent.com — feel free to swap URLs if you paste before prod deploys.

How to install in PrivateEmail

  1. Log into privateemail.com
  2. Top-right gear icon → Settings → Mail tab → Signatures
  3. Click the tiny <> (source-code) toggle in the signature editor toolbar to switch to HTML mode.
  4. Paste the HTML from the appropriate block above.
  5. Toggle back to visual mode — you should see the signature with logo and colours.
  6. Save. Send yourself a test email to confirm rendering.

If the logo image doesn’t render (some corporate clients block hotlinked images by default): right-click the preview above, save the image, then use PrivateEmail’s “Insert image” button to upload it as an inline attachment instead of a hotlink.
