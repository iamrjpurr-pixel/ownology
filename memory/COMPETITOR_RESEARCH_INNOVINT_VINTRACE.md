## 1. InnoVint (US, founded 2015)

### What it actually is
- **Cloud-based winery ERP / operating system** headquartered in the US
- **Lot-centric data model**: Lot Explorer with genealogy trace-back to originating vineyard blocks
- Marketed as "Your Winery Operating System"

### Core modules (confirmed from vendor + review sources)
| Module | Detail |
|---|---|
| **Lot management** | Lot Explorer, colour + lock-code sorting, contents, vessel group, lot genealogy |
| **TTB compliance** | Auto-generates the **TTB 5120.17** report (was Form 702); lock-backdating; audit report |
| **Case goods** | Bottle format, cases per pallet; auto-updates TTB Part I §B for bottling/transfers/tax-paid removals |
| **Costing (COGS)** | Real-time lot-based COGS, fruit cost worksheets, Lot Cost Report by category — **widely cited as InnoVint's edge over Vintrace** |
| **3D interactive tank maps** | Real-time vessel visibility (screenshots confirm; distinct visual asset) |
| **AI (shipped Jan 2026)** | AI Work Order Creation (text/voice → structured), AI Analysis Import (photo of lab notes → chemistry), AI Generated Reports (plain-language), "AI Assistant Winemaker" copilot |
| **Vineyard + cellar** | Blocks, harvest, aging, bottling — single system |
| **Custom Crush package** | Client visibility + AP Compliance included as standard |
| **Integrations** | 100% open APIs, QuickBooks, Commerce7 (DTC), CRM |
| **Mobile** | InnoApp — offline mode, QR scanning |

### What the screenshots show (Rich sent 15 Feb 2026)
- Lot detail dashboard with tabs: **Dashboard · Analysis · Additions · Vessels · History · Timeline · Composition · Cost**
- Chemistry panel: Alc 14.32%, pH 3.55, TA 6.1, RS 0.01, MA 0, VA 0.5, Free SO₂ 22 mg/L — **each analyte dated + performer-attributed** (2/28/18 FOSS, 5/11/18 ETS, 12/20/18 FOSS, etc.)
- Composition to 4 dp: Pinot Noir 99.9003 % / Cab Franc 0.0609 % / Petit Verdot 0.0368 % / Syrah 0.0019 % — TTB label-precision
- Multi-winery tenant switcher (Green Acres Winery, Hillside Estate); each with a BWN (US Bonded Winery Number)
- Vessel register: 11 barrels with individual codes (14ER007, 13SM026, …) + capacity per unit, 2 kegs
- Work orders assigned to named team members with due dates
- Analytical time-series (Brix + Temp) over 36 measurements per lot with source + notes per data point

### Pricing (public, verified)
- **Aggregator starting price**: US $149 / month — Getapp, Capterra
- **Vendor position**: Plans are customised, sales-quote required for actual pricing
- **Free trial**: Yes
- **Unlimited users** on all plans

### Ratings (Capterra, Feb 2026)
- Overall: **4.6 / 5** across 79 reviews
- Ease of use: 4.5 · Customer service: 4.8 · Value: 4.5 · Functionality: 4.3
- Reviewer base: 100 % small businesses
- G2: identified as the "best overall alternative" to Vintrace

### Common review-quote themes
- "Tighter" and "much easier to find information" than Vintrace
- "Far superior mobile app"
- "Detailed breakdown of production costs" (COGS is a defensible edge)
- "Very helpful and timely" customer service
- Widely used by **custom crush** facilities and small-to-mid wineries

## 2. Vintrace (Australia-origin, founded ~2010)

### What it actually is
- **Cloud-based wine production platform** originating in Australia, now global (670+ wineries)
- **Production / blending / lab depth** is its strong suit
- Marketed as **"the most trusted winery software platform"**
- **Mobile-first field ethos** — the entire 2-min pitch video (2020, still current per 2025 support docs) is: don't run back to the desk. Everything happens from the app in the shed.

### Core modules (confirmed from vendor video, support docs, and 2025 support portal)
| Module | Detail |
|---|---|
| **Vineyard + blocks** | Blocks, fruit bookings, harvest management |
| **Harvest Calendar + Fruit Intake** | Booking visibility, auto-calc dry-goods amounts from desired addition rates |
| **Job Management Console** | Centralised work-order hub. Create manually, via templates, or from Jobs/Vessels/Calendar pages. Assign crew, set priority, track draft → completed |
| **Work orders** | Mobile scan + submit (transfers, topping, additions) in real time |
| **Tank Map (2D facility view)** | Real-time vessel status, brand, volume, batch details. Enables **visual blending + transfers** (one tank into many) — this is Vintrace's most-praised feature in reviews |
| **Product Page** | Per-product page with latest lab results + graphable metrics over time |
| **Lab Console** | Request analysis, **graph fermentation curves** (zoom-in trends), export to CSV, **auto-ingest lab results from Baker Lab / ETS** (Vintrace-native integration) |
| **Trial Blends ("sandbox")** | Mock blends before committing. Calculates **price/gal**, current lab analysis, impact on cost + labelling limits. Retains considered trials as records |
| **Sparkling Module** | Sparkling-specific workflows (Professional tier +) |
| **QR code system** | Barrel + tank + row-post QR labels — scan-to-log in the field (vendor's own core pitch) |
| **Dashboard** | Real-time business health with **vintage-on-vintage comparison** (this year vs previous vintage/period) |
| **Compliance** | TTB reporting; **WET reporting** (Australian Wine Equalisation Tax — Vintrace-native, InnoVint lacks) |
| **Tank Controller integration** | TankNET (tank telemetry) — physical hardware bridge |
| **Integrations** | Xero (accounting), TankNET, WineDirect |
| **Mobile** | iOS + Android, offline mode, barcode + QR scanning |

### From the 2-minute demo video (verbatim value props):
- "Harvest is hard work with no time to spare"
- "View vineyard data, intake fruit weight, process fruit quickly and easily"
- "Calculate addition rates, track ferment activity, record lab results — all from your smartphone"
- "Get all your barrels labelled and tracked so they're easy to find and less likely to go in the wrong blend"
- "Manage tanks and barrels with our simple QR code system — just scan the code"
- "QR code labels on row posts to simplify picking schedules"
- "No more spreadsheets and paper all over the place"
- "Never fall behind on record-keeping again"
- "Real-time cloud dashboard, business health insights"
- "See how your business is tracking compared to previous vintage or period"
- "Stay ahead of compliance requirements — quick and easy reports in a few clicks"
- Customer testimonial: *"Without Vintrace I wouldn't have as much time to be out on the floor actually making wine"* — Brasswood
- Positioning tagline: *"Ready to take control of your business and get hours back every week?"*

### Pricing
- **G2/Capterra listed starting price**: US $95 / month ("Basic" tier)
- **Quote-based** for Estate / Custom Crush / Enterprise (majority of real deployments)
- **No free trial · No free version**
- **Independent AU estimate**: A$200 – A$800+ / month scaled by volume; no per-case pricing

### Ratings (Capterra, Feb 2026)
- Overall: **4.4 / 5** across 55 reviews
- Ease of use: 4.2 · Customer service: 4.5 · Value: 4.0 · Functionality: 4.1

### Common review-quote themes
- "Best winery software for production and work-order flow" (particularly one-tank-to-many blends)
- "Highly customizable"
- **Steeper learning curve** — "overwhelming" for new users; heavy users still need training
- Some users report it's easier for **light tasks** with fewer keystrokes than InnoVint
- **Australian compliance (WET)** is a strong reason to pick Vintrace in the AU market

## 3. Where Ownology honestly sits (Feb 2026)

### Where we win outright
1. **AI-native**, not bolt-on AI — voice logging, Weekly Reco Digest, Ownology-generated positioning drafts, quiz-driven recommendations. InnoVint has bolted AI onto a lot ledger; we started AI-first.
2. **Consumer-facing Quiz + DTC funnel** — no equivalent in either incumbent. The quiz is the DIY buyer's front door and pipes into cellar ops.
3. **Home winemakers included** — Home Winery Kit + quiz + reco. Neither incumbent serves DIY.
4. **Weekly Reco Digest** — cellar-driven consumer engagement digest. Unique.
5. **Public Cellar Journal** — winemaker vintage logs published as SEO content. Compounds year-on-year across regions.
6. **Cellar Book PDF generator** — auto-generated portfolio artefact from real cellar data.
7. **Australia + New Zealand home-market intelligence** — variety-aware home-market twin logic (Gewürz→AU Alpine, Chenin→AU Chenin, etc.). Neither incumbent has this.
8. **Founding-Member transparent pricing** — no sales-quote gauntlet at entry.
9. **Modern stack** (React 19 + tRPC + Vite) — genuinely faster interactions than either incumbent.

### Where we honestly lag (must acknowledge on the page — hiding it = losing credibility)
- **TTB 5120.17 automation** — InnoVint has, Vintrace has, Ownology doesn't yet. US wineries filing federal reports still need one of the incumbents.
- **WET automation** — Vintrace has, Ownology doesn't yet.
- **3D tank maps** — visual asset InnoVint owns.
- **Lot genealogy at InnoVint's depth** — we have batches, not full parent-tree trace-back.
- **Case goods module** — pallets/formats/tax-paid removals.
- **Custom Crush AP Compliance** — InnoVint-native.
- **Xero / QuickBooks / Commerce7 official integrations** — neither incumbent charges extra; we haven't shipped any.

### Positioning conclusion
Ownology is **not** an InnoVint replacement for a US custom-crush with 40 lots and mandatory TTB filing. It IS the right choice for:
- **AU / NZ boutique winemakers** who want AI-native workflow + quiz + digest + home-market intelligence
- **DIY / home winemakers** neither incumbent serves
- **Wineries whose compliance is manageable manually today** but whose team wants AI leverage on the tasting bench

The comparison page should be **honest, tiered, and let the buyer self-select** — not a "we beat them" chest-beat.
